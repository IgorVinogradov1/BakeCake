# Бот BakeCake

BakeCake Bot — это удобный Telegram-бот на фреймворке **aiogram 3**, разработанный для автоматизации процесса заказа готовых и кастомных тортов. Бот позволяет пользователям ознакомиться с каталогом, собрать свой уникальный торт через пошаговый конструктор и управлять своими заказами.

---

## Как установить

1. Клонируйте репозиторий на свой компьютер.
2. Убедитесь, что у вас установлен `Python` версии **3.10 или выше**.
3. Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# или для Windows (PowerShell): .venv\Scripts\Activate.ps1
```

4. Используйте `pip` для установки зависимостей:

```bash
pip install -r requirements.txt
```

---

## Настройка окружения

Создайте в корне проекта файл `.env` и укажите в нём переменную `BAKE_CAKE_TG_TOKEN`:

```env
BAKE_CAKE_TG_TOKEN=токен_вашего_бота
```

**Запуск бота:**

```bash
python main.py 
```

---

## Основные возможности

* **Согласие на ОПД**: автоматическая проверка пользователя и отправка документа (`agreement.pdf`) на обработку персональных данных перед началом заказа.
* **Каталог продукции**: возможность скачать актуальный прайс-лист и каталог тортов в формате Excel (`cakes_catalog.xlsx`).
* **Заказ готовой продукции**: быстрый выбор классических тортов из ассортимента.
* **Конструктор кастомных тортов**: пошаговый выбор параметров торта (уровни, форма, топпинг, ягоды, декор, надпись) с динамическим расчетом стоимости.
* **Полноценное оформление доставки**: сбор необходимых данных при финализации заказа (номер телефона, адрес, желаемые дата и время).
* **Личный кабинет**: просмотр и управление своими текущими и прошлыми заказами.
