# Сервис BakeCake

Проект представляет собой скрипт бота (`main.py`), для онлайн-заказа кондитерских изделий и кастомных тортов. Помогает пользователям выбирать начинку, дизайн, рассчитывать стоимость и оформлять доставку.

Пример запуска скрипта:
```
python main.py
```

### Как установить

#### 1. Клонируйте или скачайте проект

#### 2. Установите зависимости

Python 3.10.11 должен быть уже установлен. 
Затем используйте `pip` для установки зависимостей:
```
pip install -r requirements.txt
```
Рекомендуется использовать [модуль venv](https://docs.python.org/3/library/venv.html) для изоляции проекта.

##### 3. Создайте и заполните файл с ключами

Для публикации в Telegram нужно предварительно создать бота и получить его API-токен (через бота `BotFather`)

Создайте `.env` файл в корне проекта. В нём должны быть:
```
BAKE_CAKE_TG_TOKEN=ваш_токен_бота_из_BotFather
```
